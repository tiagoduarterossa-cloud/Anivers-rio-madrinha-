# Carolina 38 anos

Uma caixa de medicamento para o aniversário da madrinha Carolina (22 de novembro).

- `index.html`: a página que abre pelo QR code. Embalagem, blister com 38 comprimidos e folheto informativo.
- `impressao/caixa-A4.pdf`: a caixa para recortar e dobrar (cartolina A4, tamanho real).
- `impressao/folheto-A4.pdf`: o folheto em papel que vai dentro da caixa.
- `impressao/gerar.py`: volta a gerar `caixa.html` e `folheto.html` depois de mudar textos no `index.html`.

O QR code aponta para https://tiagoduarterossa-cloud.github.io/Anivers-rio-madrinha-/ (é preciso ativar o GitHub Pages no repositório).
