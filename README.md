# Madrinha, o jogo

Um jogo para o telemóvel, feito para os 38 anos da madrinha Carolina (22 de novembro).

- Três níveis da vida do afilhado (o batizado, a infância, a adolescência). Inclina-se o telemóvel, ou usa-se o dedo, para apanhar o que cai.
- Nível 4, a farmácia da madrinha: um blister com 6 comprimidos. Cada um tem uma pergunta, e cada resposta certa desbloqueia uma fotografia. No fim aparece o memorial com todas.
- Nível final: 38 velas num bolo, que se apagam a soprar para o microfone.
- No fim toca o "Parabéns a você" e aparece uma carta.

Tudo está em `index.html`. Os textos de cada nível estão na lista `LEVELS` e as perguntas na lista `PERGUNTAS`, no início do script. As fotografias vão para a pasta `fotos/` (1.jpg a 6.jpg).

Para funcionar no telemóvel, ativa o GitHub Pages: https://tiagoduarterossa-cloud.github.io/Anivers-rio-madrinha-/
A inclinação e o microfone só funcionam por https (GitHub Pages), não ao abrir o ficheiro diretamente.

## Para imprimir (pasta `impressao/`)

- `capa-A4.pdf`: capa para uma caixa de DVD normal (verso, lombada e frente), com screenshots do jogo e o QR code. A4, tamanho real.
- `cartao-A4.pdf`: dois cartões de ativação com o QR code, para ir dentro da caixa.
