# Madrinha, o jogo

Um jogo para o telemóvel, feito para os 38 anos da madrinha Carolina (22 de novembro).

- Três níveis da vida do afilhado (o batizado, a infância, a adolescência). Inclina-se o telemóvel, ou usa-se o dedo, para apanhar o que cai.
- Nível final: 38 velas num bolo, que se apagam a soprar para o microfone.
- No fim toca o "Parabéns a você" e aparece uma carta.

Tudo está em `index.html`. Os textos de cada nível estão na lista `LEVELS`, no início do script.

Para funcionar no telemóvel, ativa o GitHub Pages: https://tiagoduarterossa-cloud.github.io/Anivers-rio-madrinha-/
A inclinação e o microfone só funcionam por https (GitHub Pages), não ao abrir o ficheiro diretamente.
